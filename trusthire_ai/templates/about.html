ABOUT TRUSTHIRE AI

Useful signals, not false certainty.

TrustHire AI is a job-post screening prototype built to help people pause and examine an offer.

01

How analysis works

The app normalizes common obfuscations, checks configurable phrases and signals, and optionally combines them with a scikit-learn classifier when you provide a compatible trained model.

Matched wording and explanations are returned with each result. A phrase match is not proof of fraud; legitimate posts can contain similar words in a warning or disclaimer.

02

Dataset & model status

EMSCAD (the Employment Scam Aegean Dataset) is a commonly used research dataset. No EMSCAD data is bundled here and no accuracy claims are made.

Train a TF-IDF + Logistic Regression pipeline from a properly licensed, labelled dataset before using model probabilities in real decisions. See model/train_model.py.

03

Technology

Flask REST/web routes, SQLite, scikit-learn/joblib integration, semantic HTML, responsive CSS and Chart.js visualizations.

The current default is rule-based and demonstrative. An absent model is explicitly reported instead of pretending an ML result exists.

Independent verification matters. Search for the company site yourself, contact the employer using details from that official site, and never share OTPs, PINs or passwords with a recruiter.
